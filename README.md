# Invitación digital de bautizo

Invitación web (HTML, CSS y JavaScript, sin dependencias) con moño que se desata con dos toques, guirnalda de perlas, paloma, tres símbolos interactivos, sonido sintetizado, cuenta regresiva, confirmación por WhatsApp y pases personalizados.

## Personalizar
Edita el bloque `CONFIG` al inicio del `<script>` de `index.html`: nombre, fecha, padres, padrinos, lugares, programa, regalos y hashtag.

- `tema`: `"perla"`, `"celeste"` o `"rosa"`.
- `genero`: `"niño"` o `"niña"` (ajusta los textos).
- `foto`: ruta o URL opcional para mostrar una foto circular en la portada.

## Pases personalizados
Agrega `#generar-pases` al enlace público para abrir el generador. Cada invitado recibe un enlace como `.../#familia-lopez-4`.

## Publicar en GitHub Pages
Settings → Pages → Deploy from a branch → `main` / `(root)`.
